Utopia describes a scale the same way I do, as a minimum and a maximum viewport with a base size and a ratio at each, and generates the clamp() values for type and for spacing. I still write my own generator so the rule lives in the repo, but when a designer wants to try a ratio before we change code, this is where we sit down together and try it.
