Every token tool used to invent its own JSON shape, and every migration between tools meant rewriting the source of truth. This group's format, `$value` and `$type` with aliases in braces, is the closest thing we have to a standard, and it is what my [token pipeline series](/showcase/plinth/demo/tutorials/token-pipeline-source) is written against. Read the format draft before inventing your own fields.
