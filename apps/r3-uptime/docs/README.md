# R3 Uptime Feature Docs

This folder documents the product features observed in `apps/uptime` from a behavior-first perspective so they can be reimplemented in `apps/r3-uptime` with a different framework.

## Scope

These docs focus on:

- user-facing behavior
- feature rules
- statuses and lifecycles
- defaults and limits
- feature interactions

These docs intentionally avoid framework-specific implementation details.
